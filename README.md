# Rimzim Maliwal — Portfolio

Personal frontend developer portfolio built with React, TypeScript and Vite.

## Highlights

- Dark-first visual design with optional light theme
- Responsive navigation and mobile layout
- Custom illustrated hero built with CSS
- Featured project showcases for JobFlow and JobFlow AI
- Experience, skills, about and contact sections
- Accessible semantic structure and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

The project is ready to deploy on Vercel. Import this GitHub repository, keep the default Vite build settings, and deploy.
